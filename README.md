# IW-Email-Sender

Application for sending scheduled emails automatically based on predefined settings set by the sender to a larger group of people.

## About the Project

This application is developed using **Java Spring Boot**, leveraging several supported dependencies. The project uses **Java 21**, **Maven**, and **Spring Boot 3.5.7**, packaged as a JAR file. The application uses **PostgreSQL** as its database.

### Dependencies

The project uses the following dependencies:

- Spring Boot Starter Data JPA
- Spring Boot Starter Mail
- Spring Boot Starter Security
- Spring Boot Starter Web
- Liquibase Core
- Spring Boot Docker Compose
- PostgreSQL Driver
- Spring Boot Starter Test
- Spring Security Test
- Commons Validator
- MapStruct
- Spring Batch Core
- Spring Retry
- Spring Boot Starter AOP

### Dependency Overview

- **Spring Boot Starters** – core components for JPA, Mail, Web, and Security
- **Liquibase** – database migration tool
- **PostgreSQL Driver** – for connecting to PostgreSQL database
- **Spring Boot Docker Compose** – integration with Docker at runtime
- **MapStruct** – object mapping (DTOs)
- **Commons Validator** – data validation
- **Spring Batch & Spring Retry** – batch processing and retry mechanisms
- **AOP and testing libraries** – for aspects and unit testing
